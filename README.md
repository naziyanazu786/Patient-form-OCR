# Patient Form OCR Processor

A Python-based solution for extracting text from scanned patient assessment forms using OCR, converting the data to JSON format, and storing it in a SQL database.

## Features

- Extract text from PDF and JPEG files using Tesseract OCR
- Process and structure extracted data into JSON format
- Store structured data in SQLite database
- Support for batch processing multiple forms

## Prerequisites

- Python 3.8+
- Tesseract OCR
- Required Python packages (see requirements.txt)
